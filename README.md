# AutoDev AI

Autonomous AI Software Engineer platform.

## Architecture

- Frontend: Next.js + React + Tailwind CSS
- Backend: Python + FastAPI
- Database/Auth: Supabase
- AI: Google Gemini
- Orchestration: Custom Python + LangGraph
- Queue: Redis + workers
- Repository: GitHub + local workspace
- Deployment: Vercel
